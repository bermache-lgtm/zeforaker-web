# Zeforaker Service · Landing

Sitio web de ZEFORAKER SERVICE (Servicios Generales).

## Publicar con GitHub Pages
1. Sube `index.html` y la carpeta `img/` a la raíz del repositorio.
2. En el repositorio: **Settings → Pages → Build and deployment**, elige *Deploy from a branch*, rama `main` y carpeta `/ (root)`.
3. En unos minutos la web estará en `https://<usuario>.github.io/<repositorio>/`.
